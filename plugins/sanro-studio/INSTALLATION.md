# Installation and configuration — SANRO Studio1.0.0

1. Verify the release ZIP against SHA256SUMS. Install through WordPress Plugins → Upload, or the approved staging installer. Replacing this plugin preserves existing design/order data and server configuration. Do not install staging utilities on production.
2. Ensure WooCommerce is active, PHP8.1+ with GD/FreeType, OpenSSL, JSON, fileinfo and writable private storage outside the document root. Private master/preview storage is provisioned through the plugin's existing guarded setup; unsafe/unavailable paths are reported and fail closed.
3. SANRO Studio → Pengaturan: choose the editor WordPress page. Set per-product pricing, size/colour/mockup mapping and print zones through WooCommerce product administration. Existing validated configuration is retained on upgrade. Buyer/editor/draft/pricing/production flags follow the hosting's explicit configuration; no activation changes are made silently by this ZIP.
4. Google Drive is optional and initially NOT CONFIGURED/OFF. Administrator may later register a web OAuth client and configure its exact Redirect URI displayed in the Google Drive settings tab. Save Client ID/Secret, existing folder ID and optional restricted Picker API key directly over HTTPS. Connect through Google, select the existing folder, and use Test Connection. The plugin never creates a replacement root or public permission.
5. Enable automatic export only after connection/folder testing succeeds. The checkbox saves the Administrator preference; server safety gates must also permit DRIVE_AUTO_PROVISION, VERIFIED_DRIVE_ATTACHMENT and the desired package/master export. Explicit server OFF remains authoritative and the settings page reports effective runtime state. Disconnect erases local tokens, disables auto export, invalidates pending authorization state and attempts official revocation.
6. Production folders/jobs require a Woo paid order or an authorized ready-for-production decision. Private local previews remain usable with Drive disabled. Physical print approval is separate. Keep storage GC OFF for this release's staging installation.

Never put credentials in release files, public WordPress options, logs, screenshots or repository commits. WordPress secure-auth salt protects encrypted tokens; changing that salt requires reconnecting Google. OAuth testing-mode token lifetime and consent/API configuration belong to post-release Owner setup.
