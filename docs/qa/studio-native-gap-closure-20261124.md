## Batas implementasi dan storage

- Collection menyimpan metadata privat non-autoload, referensi immutable dan durable email HMAC key terpisah dari login salts. Rotasi WP auth salt tidak menghilangkan ownership. Session bearer hash berumur 1 jam; kode email 30 menit/single-use dan budget IP+recipient yang sudah ada. Tidak mengandalkan guest nonce untuk ownership. Secret tidak di URL query/HTML/config; fragment share dibuang dari history sebelum fetch. Resave snapshot mencabut share lama. Shared fork tidak mewarisi proof email, payment, Woo session atau origin collection; owner reopen boleh memperbarui entry miliknya melalui draft independen.
- Kapasitas default teknis 512 MiB aggregate, dapat diatur melalui `SANRO_STUDIO_PRIVATE_QUOTA_BYTES`; reserve disk 16 MiB. Ini batas keselamatan, bukan paket/kuota komersial Owner. Immutable original/revisions/fork semuanya dihitung. Semua root harus existing 0700 di luar WP/document root; file baru 0600. Capacity error 507, lease busy 503 pada master/preview API.
- GC **default OFF** (`SANRO_STUDIO_ENABLE_STORAGE_GC`), tidak ada cron. Hanya tindakan admin ber-capability + nonce setelah opt-in terpisah. Grace orphan 24 jam melindungi write/bind yang terhenti. Root inventory 50.000 file/5s; option reference scan dan Woo-order pagination dibatasi waktu; incomplete/corrupt/unsupported scans menolak deletion. Referensi aktif, seluruh order namespace, symlink, unknown names dan semua artefak DTF/order tidak dihapus. Tidak menetapkan retensi order baru. Tidak menjalankan GC terhadap storage hosting.
- Master bridge privat yang sudah ada tetap dipakai ketika Drive OFF; koleksi mem-pin sumber agar TTL draft tidak menghilangkannya. Belum ada klaim file telah dipindahkan ke Drive atau storage produksi final terverifikasi. Kuota penuh menolak salinan/upload, bukan menghapus master lama.
- Remove-background lokal menghapus warna latar polos yang tersambung ke tepi, bukan semantic AI segmenter. Gambar transparan, hasil tanpa foreground, input invalid, budget habis atau output tidak sah ditolak tanpa mengganti sumber. Tidak ada HTTP provider/dependency berbayar baru. Error memori/waktu tidak mengizinkan file cetak parsial.
- Matrix mockup memilih exact product/color/size/side lalu size `*`. Kombinasi tanpa foto menggunakan garment standar, bukan foto warna/size lain. Preview derived mempertahankan aspek area cetak, zone per sisi, dan memakai foto produk yang dipilih; preview bukan master produksi. Foto CDN harus mendukung CORS untuk canvas; failure menolak upload preview, tidak membuat klaim keberhasilan.
